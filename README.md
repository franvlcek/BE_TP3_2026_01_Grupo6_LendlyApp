LendlyApp

Aplicación móvil Android desarrollada con Kotlin y Jetpack Compose para la gestión de préstamos, pagos y servicios financieros.

Descripción:

LendlyApp es una aplicación diseñada para brindar a los usuarios una experiencia simple y segura en la administración de servicios financieros. La plataforma permite autenticarse mediante una API REST, acceder a información personal, gestionar préstamos y visualizar datos relevantes de la cuenta.

El proyecto fue desarrollado siguiendo buenas prácticas de arquitectura Android moderna, utilizando MVVM, inyección de dependencias y componentes de Jetpack.

Arquitectura:

El proyecto implementa el patrón MVVM (Model - View - ViewModel) para garantizar una correcta separación de responsabilidades.

Tecnologías Utilizadas:

Kotlin:	Lenguaje principal
Jetpack: Compose	Desarrollo de interfaz de usuario
Material 3:	Componentes visuales
Navigation Compose:	Navegación entre pantallas
Retrofit:	Consumo de API REST
Hilt:	Inyección de dependencias
Coroutines:	Operaciones asíncronas
ViewModel:	Gestión de estado
State Management:	UI reactiva

Instalación:
Clonar el repositorio:
git clone <url-del-repositorio>
Abrir el proyecto en Android Studio.
Sincronizar dependencias Gradle.
Configurar la URL de la API en el entorno correspondiente.
Ejecutar la aplicación en un emulador o dispositivo Android.
